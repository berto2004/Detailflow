# Test Register — DetailFlow

1. Hapus folder `.next` jika ada.
2. Jalankan `npm run db:migrate:local`.
3. Jalankan `npm run dev`.
4. Buka `http://localhost:3000/login`.
5. Klik **Belum punya akun? Daftar**.
6. Isi nama, email, dan password minimal 8 karakter.
7. Klik **Buat Akun**.

Jika masih gagal, lihat Terminal tempat `npm run dev` berjalan. Kirim satu baris error merah pertama ke Koda.
