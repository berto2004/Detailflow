# Test Lokal DetailFlow

1. `npm install`
2. `npm run db:migrate:local`
3. `npm run dev`
4. Buka http://localhost:3000/login
5. Klik **Belum punya akun? Daftar**
6. Isi nama, email, password minimal 8 karakter
7. Klik **Buat Akun**
8. Isi nama studio pada onboarding

Jika CSS masih terlihat polos, hentikan dev server lalu jalankan kembali `npm run dev` setelah `npm install` selesai.
